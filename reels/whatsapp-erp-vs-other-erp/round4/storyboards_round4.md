# WhatsApp ERP vs Other ERP: redesigned storyboards (round 4)
Reel 59.8 s · 9:16 · palette P3 Sage Calm · VO `vo_clean.wav` · HeyGen face already received (F1 2.2–6.0 s, F2 29.0–31.9 s, F3 54.7–59.8 s, about 20%).

**Two rules in all three storyboards**
1. **Whenever "WhatsApp ERP" is on screen, the phone and the dashboard are on screen together**, joined by a sync line. What happens in the chat is what changes on the dashboard (ring on the card that changed + the matching Live Alerts row).
2. **Every WhatsApp beat is a complete flow**, not one message (see `flows_sheet.png`):
   - **Attendance (labour):** check-in reminder template → tap *Check-in* → "share location" → live location bubble → "Check-in Successful (inside radius)" → dashboard *Today Total Present* + check-in alert.
   - **Maal inward (store):** "Hi" → *Main Menu* → *View Options* list → *Material Inward* → Flow form (vendor, item, qty, challan photo) → "GRN-101 Created" + PDF → dashboard *Inventory* + GRN alert.
   - **Production (supervisor):** 6 PM *Production Update* template → *Update Production* → Flow form (machine, item, OK qty, rejection) → *Submit* → "Production Logged" + daily report PDF → dashboard *Today Production 1,240* + M-4 alert.
   The script gives these three beats 2.7 s, 2.8 s and 4.2 s, so each flow plays at about 0.6–0.9 s per step, and the chat stays on screen so the whole flow can be read on pause.

All names and numbers are sample data. Dashboard = your `hivon-erp-dashboard.svg` (re-texted), chat = your Hivon chat look (Meta template parts: header, body, "Powered by Hivon Automations" footer, buttons, list, Flow form).
